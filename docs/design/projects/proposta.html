Sobre o projeto "Cadu" em Configurações

A janela tinha como projeto a sua pasta pessoal (~), que se chama "cadu", porque o workspace abriu nela. Os terminais de bkdg-center ficaram dentro desse projeto. Com a página Projetos, as Configurações passam a ser sempre de um projeto que você escolheu, e a pasta pessoal não vira projeto sozinha.
