O que vai para o pé do trilho

O que vale para todos os projetos e se usa de vez em quando. O que já está na barra de cima não se repete.

No pé do trilhoPor quêFica?
ProjectsGlobal (todos os projetos), usado de vez em quando; a porta para a página de cada projeto.Sim
AutomationsGlobal, passivo; o ícone ganha um ponto quando uma falhou.Sim
MachinesGlobal, passivo, só com o Tailscale; hoje mora no cartão do SSH.Talvez, só se houver Tailscale
Quadro (kanban)Global, mas já está na barra de cima, ao lado do sino.Não, ficaria repetido
ConfiguraçõesJá estão na barra de cima e no ⌘,.Não

Quem abre o quê

Projeto no trilhoAbre os terminais dele (as abas de cima) e o painel.
Projects no péAbre a página com todos os projetos.
Cartão na página ProjectsAbre a página daquele projeto: sessões, memória, automações, configurações.
New terminal (tudo fechado)Abre um terminal na pasta pessoal, sem projeto. As abas sem projeto aparecem quando nenhum projeto está aceso no trilho.
