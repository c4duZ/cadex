---
name: cadex-task
description: Use when you start working on a task, change what you are doing, or the work is ready for review, in a Cadex task (a git worktree Cadex made with New Task).
---

Cadex shows each task's status and a short comment to the owner. Read how to keep them right:

```
cadex skills get tasks
```

In short: `cadex worktree status doing` when you start, `cadex worktree comment "<what>"` as you
go, `cadex worktree status review` and `cadex notify "<what is ready>"` when it is ready.
